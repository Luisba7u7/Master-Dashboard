## Nivel 0-10: Puntuación de Código en Voz Alta

**Objetivo del nivel:**
Si te piden que dictes una línea de código o expliques un error de sintaxis en una llamada de voz, no puedes decir "el cosito ese curvado". Tienes que saber el nombre oficial de cada símbolo.

**Conceptos exactos:**
*   `{ }` : *Curly braces* (Llaves).
*   `[ ]` : *Square brackets* o simplemente *Brackets* (Corchetes).
*   `( )` : *Parentheses* (Paréntesis).
*   `< >` : *Angle brackets* (Pico-paréntesis).
*   `:` : *Colon* (Dos puntos).
*   `;` : *Semicolon* (Punto y coma).
*   `" "` : *Double quotes* (Comillas dobles).
*   `' '` : *Single quotes* (Comillas simples).
*   `` ` `` : *Backticks* (Acento grave / Template literals).
*   `/` : *Slash* o *Forward slash*.
*   `\` : *Backslash*.
*   `-` : *Hyphen* o *Dash*.
*   `_` : *Underscore* (Guion bajo).
*   `#` : *Hash* o *Pound*.
*   `*` : *Asterisk* o *Star*.

**Ejercicios:**
1.  Toma el objeto `const user = { name: "Juan", age: 25 };`. Léelo en voz alta así: *"Const user equals curly brace name colon double quotes Juan double quotes comma age colon twenty-five curly brace semicolon"*.

**Tiempo estimado:**
*   1 semana.

## Nivel 11-20: Verbos de Acción Informática

**Objetivo del nivel:**
Saber describir QUÉ está haciendo el código bajo el capó usando los verbos que emplea la industria.

**Conceptos exactos:**
*   *Fetch / Retrieve:* Traer o recuperar datos del servidor.
*   *Push / Submit:* Enviar datos al servidor.
*   *Parse:* Analizar y convertir un formato a otro (Ej. Parsear JSON a Objeto).
*   *Render:* Dibujar o pintar elementos gráficos en la pantalla.
*   *Deploy:* Desplegar código a producción (NO se dice "upload the code").
*   *Trigger:* Disparar un evento (Ej. "Clicking the button triggers the function").
*   *Nest:* Anidar (Meter un `if` dentro de otro `if`).
*   *Iterate / Loop through:* Recorrer un Array.
*   *Hardcode:* Quemar datos. (Escribir algo directamente en el código en lugar de usar una variable).

**Ejercicios:**
1.  Explícale a tu patito de hule (Rubber Duck Debugging) en voz alta, en inglés, qué hace la función de Login de tu último proyecto usando estos verbos.

**Tiempo estimado:**
*   1 semana.

## Nivel 21-30: Lectura Quirúrgica y Stack Traces

**Objetivo del nivel:**
Perder el miedo a leer la documentación de Mozilla (MDN) y a entender los bloques rojos de error de la terminal.

**Conceptos exactos:**
*   **Anatomía de la Documentación (MDN / React Docs):**
    *   *Overview/Description:* El resumen de qué hace el método.
    *   *Syntax:* Cómo se escribe (`arr.reduce(callback, initialValue)`).
    *   *Parameters:* Qué necesita recibir para funcionar.
    *   *Return Value:* Qué expulsa al terminar.
*   **Vocabulario del Stack Trace (Errores):**
    *   *Undefined behavior:* Comportamiento indefinido.
    *   *Deprecation warning:* Advertencia de que ese código es viejo y será eliminado pronto.
    *   *Type Mismatch:* Intentaste sumar una Letra y un Número.
    *   *Out of bounds:* Intentaste acceder al elemento 10 de un array que solo tiene 5.

**Ejercicios:**
1.  Entra a `developer.mozilla.org` en INGLÉS. Busca el método `Array.prototype.reduce()`. Lee toda la página y anota las 5 palabras que no entiendas.

**Tiempo estimado:**
*   2 semanas.

## Nivel 31-40: Dorking (Búsquedas Nivel Senior)

**Objetivo del nivel:**
Dejar de buscar en español "Cómo centrar un div". Todas las respuestas complejas viven en foros anglosajones.

**Conceptos exactos:**
*   **Fórmulas de búsqueda en Google:**
    *   `How to [action] in [technology] without [restriction]` (Ej. How to center a div in CSS without flexbox).
    *   `Why is my [element] not [action]?` (Ej. Why is my React component not re-rendering?).
    *   `Difference between [A] and [B] in [tech]` (Ej. Difference between let and var in JS).
*   **Uso de Operadores (Google Dorks):**
    *   `site:stackoverflow.com "TypeError: Cannot read property 'map' of undefined"` (Obliga a Google a buscar ese error exacto SOLO en StackOverflow).

**Ejercicios:**
1.  Oblígate durante toda una semana a buscar absolutamente todas tus dudas de programación en Google EXCLUSIVAMENTE en inglés.

**Tiempo estimado:**
*   1 semana.

## Nivel 41-50: Commits Imperativos y Pull Requests

**Objetivo del nivel:**
El 70% de la comunicación en empresas de software remoto es asíncrona y escrita (GitHub). Tienes que aprender a escribir reportes técnicos.

**Conceptos exactos:**
*   **La Regla de Oro de los Commits:** El Modo Imperativo. Le estás dando una ORDEN al código base.
    *   *MAL (Pasado):* `Added login button`.
    *   *MAL (Gerundio):* `Adding login button`.
    *   *BIEN (Imperativo):* `Add login button`.
    *   *BIEN:* `Fix memory leak in user feed`.
*   **Anatomía de un buen Pull Request (PR):**
    *   *What does this PR do?* (Qué hace).
    *   *Why is it needed?* (Por qué se necesita).
    *   *How to test it?* (Cómo el QA puede probarlo localmente).

**Ejercicios:**
1.  Configura todo tu VS Code en inglés. A partir de hoy, NINGÚN commit que hagas en tus proyectos personales puede estar en español. Todos deben usar el modo Imperativo en inglés.

**Tiempo estimado:**
*   Práctica constante.
